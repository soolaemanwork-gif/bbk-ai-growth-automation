# Project Evidence

This directory contains supporting evidence for the scale, performance, and implementation claims documented in the main project README.

## Google Search Console Performance

![Google Search Console — 12 Month Performance](./gsc-performance-12-months.png)

**Verified metrics:**

- 24,307 Google Search impressions
- 883 organic clicks
- Measurement period: 12 months
- Market: Indonesia

This evidence is included to distinguish measured production results from architectural or implementation claims.

## Evidence Policy

Only metrics that can be supported by production data, system exports, source code, or platform reports are presented as verified results.

Claims that cannot be independently supported are either described as partially verified or excluded from the portfolio.

## Product Sitemap Scale

The production WooCommerce catalog is distributed across multiple product sitemap files:

- [`product-sitemap.xml`](./product-sitemap.xml)
- [`product-sitemap2.xml`](./product-sitemap2.xml)
- [`product-sitemap3.xml`](./product-sitemap3.xml)

Together, these sitemap files provide production evidence of the scale of the live e-commerce catalog.

**What this evidence supports:**

- Large-scale product catalog deployment
- Thousands of product URLs exposed through the production sitemap infrastructure
- Production implementation beyond a prototype environment

The sitemap files demonstrate the scale of the live catalog. They do not, by themselves, prove that every listed product was published through the automation pipeline.
